# Front-End AI Engineering — Capstone Project

Capstone repository for the **Front-End AI Engineering** track of the FlyRank AI
Internship. Built module by module, from environment setup through a final
capstone project, using AI-assisted development as the core working method.

## About This Track

A 4-module curriculum — site foundations, responsive execution, storefront
patterns, and AI implementation QA — ending in a capstone project. Mentored by
Adnan Travljanin (Senior Solutions Architect, Praella).

## Status

🚧 **Setup phase.** Project idea and tech stack scaffolding are in progress.
This README will be updated once the capstone direction is finalized.

## Tech Stack

- React
- JavaScript (ES6+)
- HTML5 / CSS3
- Node.js (LTS)

Stack details and conventions are documented in [`CLAUDE.md`](./CLAUDE.md).

## Getting Started

```bash
# Clone the repository
git clone https://github.com/Ri-Mon/frontend-ai-engineering-project.git
cd frontend-ai-engineering-project

# Install dependencies (once the project is scaffolded)
npm install

# Run the dev server
npm run dev
```
