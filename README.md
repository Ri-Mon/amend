# Front-End AI Engineering — Capstone Project

Capstone repository for the **Front-End AI Engineering** track of the
[FlyRank AI Internship](https://internship.flyrank.ai/). Built module by
module, from environment setup through a final capstone project, using
AI-assisted development as the core working method.

## About This Track

A 4-module curriculum — site foundations, responsive execution, storefront
patterns, and AI implementation QA — ending in a capstone project. See the
[Official Track Page](https://internship.flyrank.ai/tracks/fe) for full
details.


## Documentation & Process

Curious how this project came together — the decisions, the AI prompts, the
mistakes and rewrites along the way? That's all tracked separately, in the
full internship journal: [flyrank-ai-internship](https://github.com/Ri-Mon/flyrank-ai-internship).
Start there if you want the story behind the code, not just the code itself.

This repo holds the capstone build. A few standalone practice exercises from
earlier in the track (confirmed so far: FE-03) live in their own separate
repos rather than here.

## Running the App

```bash
npm install
npm run dev -- --host 0.0.0.0 --port 3000
```

Then open http://localhost:3000 in the browser.

## Getting Started

```bash
# Clone the repository
git clone https://github.com/Ri-Mon/frontend-ai-engineering-project.git
cd frontend-ai-engineering-project

# Install dependencies (once the project is scaffolded)
npm install

# Run the dev server
npm run dev
```
